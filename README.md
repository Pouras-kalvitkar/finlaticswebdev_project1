# Pouras Kalvitkar Portfolio

A responsive, single-page portfolio for Pouras Kalvitkar, an AI & Data Science student from Navi Mumbai.

## Highlights

- Accessible, responsive static site with no build step
- Personal profile, experience, education, technical toolkit, and direct contact links
- Project sections for BlinkBridge AI, tuberculosis X-ray detection, speech-to-speech translation, and a Myntra-inspired e-commerce application
- No stock photo or placeholder image dependency: the site uses an original initials-based visual instead

## Run locally

Open `index.html` in a browser, or use the included script:

```bash
npm start
```

## Deploy

The site is static and can be deployed on GitHub Pages, Vercel, Netlify, or any standard static host.
